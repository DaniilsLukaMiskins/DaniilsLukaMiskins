## Featured projects

### [HabitTracker](https://github.com/DaniilsLukaMiskins/HabitTracker)

An Android app for tracking habits. Pick a date, mark a habit as complete, and review your history. The mobile app sends updates to an ASP.NET Core API that stores them in SQL Server.

`C#` `.NET MAUI` `ASP.NET Core` `SQL Server`

### [Nemesis AI](https://github.com/DaniilsLukaMiskins/Nemesis-Minecraft-mod)

A Minecraft mod our team built for a hackathon. Keep hitting the boss with projectiles and it starts approaching in a zigzag. It also remembers routes players take and uses them to predict ambush points.

`Java` `Fabric` `Minecraft`

### [DupeFinder](https://github.com/DaniilsLukaMiskins/DupeFinder)

A command-line tool that finds duplicate files in a downloads folder, even when their names differ. It groups files by SHA-256 hash and exports the results to CSV.

`C#` `SHA-256` `CSV`
